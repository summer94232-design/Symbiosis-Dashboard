# lint 清理與讀取可靠性 — 2026-09-09

版本更新為 `v26.9.9`。本輪從 54 個 lint 錯誤、8 個警告開始，完成程式修正；沒有關閉 lint 規則或加入新的停用註解。

## 行為修正

- 歷史損益、產業脈絡、產業地圖與自選股的讀取增加請求序號與帳號檢查。較慢的舊回覆不會蓋掉較新的結果；離開頁面後的回覆不再更新該頁狀態。讀取失敗顯示錯誤，並結束初始載入狀態。背景重讀期間保留上一次清單。
- 自選股的台股價格直接從共用股價衍生，不再透過 effect 複製到另一份清單狀態。
- 每日簡報初始化時檢查新聞快取格式；行程與任務讀取失敗會提示，頁面離開後忽略過期回覆。共用資料版本改變時重新讀取行程與任務。
- KMS 圖譜讀取失敗不再永久停在載入中。指定筆記連結改為明確展開，避免資料更新時重複切換展開／收合；切换路由後忽略舊回覆。
- 行事曆設定的 Google 連結初始化統一處理成功、失敗與載入結束，避免失敗後一直等待；Strict Mode 的 effect 重跑共用同一個初始化請求。OAuth 協定、token 儲存與 F17 的設計未變更。
- 持倉族群編輯在使用者開啟編輯時帶入原值；App 於路由改變時同步調整選單狀態。
- 指數比較資料的自動查詢保留由使用者切換檢視觸發，讀取最新狀態，不因讀取失敗而自動反覆重試。

## 程式整理與防止復發

- 補齊圖表、匯入資料、圖示、股票歷史資料等型別；移除無使用入口的函式、未使用變數與不規則空白。
- 將主題與市值 Context 的 hook 分離，修正快速重新載入規則。
- `npm run lint` 加入 `--max-warnings 0`，錯誤或警告都會造成檢查失敗。
- CI 的 lint 改為必要檢查，移除原有的 `continue-on-error`。此工作流程仍未推送或於遠端執行。
- 排除 `.local-tools` 內產生的工具、快取與報告；正式程式與原有規則仍受檢查。

## 驗證

- 全專案 lint：0 錯誤、0 警告。
- 建置通過，仍有既有的大型產物提示。
- 原有 260 項測試通過，新增 8 項讀取回歸測試通過：四個頁面各驗證「舊回覆不得覆寫新結果」與「失敗必須結束載入並顯示錯誤」。
- 本輪未重新執行模擬器測試或完整瀏覽器驗收，未部署、未修改正式資料。

## 待辦

發布前以專用測試帳號驗收真實 Firebase 離線恢復、Google 授權與事件同步，以及主要頁面操作。F16、F17 與歷史資料差異仍依使用者指示暫緩。
