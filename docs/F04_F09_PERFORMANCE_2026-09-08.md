# F04、F09 修正紀錄（2026-09-08）

## F04：自訂區間年化報酬

自訂區間改採期初、期末完整帳戶淨值及期間外部出入金求 XIRR。淨值包含持股市值、帳戶現金，並扣除融資本金；賣出收回本金與已入帳股利包含在現金，不再只加回已實現獲利或重複加計股利。

例如一年期初 100,000、期末 110,000，無外部出入金時，無論持股全部保留、部分賣出或全部賣出留現金，年化報酬均為 10%。

- 歷史端點需要確切日期的淨值快照；設定起始日可使用設定淨值。缺少資料時顯示原因，不拿今日價格或持倉成本替代。
- 期末為今日且尚無快照時，使用具有完整有效報價的今日帳戶淨值。
- 端點視為當日結束；出入金採 (起日, 迄日]。入金為投資人流出，出金為流入。
- 新計算使用 365 天年化。無可辨識單一解時不顯示猜測數字；本金全部損失顯示 −100%，並註明一般 XIRR 無有限解。
- 更改日期會使先前未完成的計算失效，避免舊結果覆蓋新區間。

本次範圍是自訂區間年化計算，不代表本頁其他年度／交易績效公式均已重寫。

## F09：資產報酬曲線

報酬因子為零時保留 −100% 全損結果，不再以零變動略過。負淨值、非有限值、資金流與期末流量假設不相容，或零淨值後重新入金等無法延續計算的區段，回傳缺值並顯示原因；曲線不跨缺值連接，加權指數獨立計算。

目前仍是相鄰快照的近似 TWR，假設期間淨流量發生在期末；缺少每次出入金時估值會有誤差。零淨值後的新投資期間需另選正淨值起點。
