# 本機 AI 模型狀態修正（v26.10.4.3）

## 已確認原因

本機 5187 後端原先從限制網路的執行環境啟動。Firebase Admin 下載 Google 的登入驗證公開金鑰時收到 `EACCES`。SDK 將這類公開金鑰下載錯誤包成 `auth/argument-error`，系統原先因此錯誤回覆「登入憑證失效，請重新登入」。

前端又把尚未取得設定時的四個預設模型全部設為不可用，所以使用者看到四個「未啟用」。這不代表 Gemini API Key 被停用。

已以具正常網路權限的方式重新啟動既有本機預覽，實際登入狀態請求成功。兩個 Gemini 可選；GPT 與 Claude 維持未啟用。Google 帳號與專案維持原核准設定，每月 NT$150 預算不變。

## 修正

- 明確區分設定載入中、載入失敗，以及後端確認模型未啟用；未取得設定時不再捏造四個未啟用狀態。
- 載入失敗直接顯示「重試連線」。不自動輪詢、不自動重送付費問題；同時重試不會重複查詢。
- 設定錯誤與對話錯誤分開，重新載入設定不會清掉尚未成功問題的重試提示。
- 登入身分切換後重新載入設定，忽略舊帳號遲到的結果；開始新對話不再丟棄正在載入的帳號設定。
- 載入設定時避免同時寫入偏好；模型、送出與研究接續操作在設定未就緒時暫停。
- Firebase 公開金鑰下載失敗改回覆驗證服務連線失敗（503）。真正過期、撤銷或無效的登入仍回覆 401。驗證與撤銷檢查保留，未通過時仍不讀取使用者資料或額度。
