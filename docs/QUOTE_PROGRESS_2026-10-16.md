# 持股提早顯示與歷史資料共用（v26.10.16.1）

使用者先批准 A–E 實作及本機驗證，之後明確批准本批部署。正式發布使用固定20項 Functions-only 覆寫入口；富邦歷史帳號實測未完成，主源切換保持停用。

## 現價與資產趨勢

- 全域 PriceProvider 留在路由外。富果逐檔完成就儲存、顯示持股；富邦 TSE／OTC 快照繼續在背景執行，非持股可先完成。最終 API 回傳仍代表整批完成，不以提早解除 loading 假裝整批成功。
- 畫面區分「持股更新中（完成／總數）」及「持股已更新，其他股票更新中」。正常系統內切換至資產趨勢、知識庫不取消工作；關閉、重新整理、瀏覽器暫停與帳號變更不承諾繼續。
- 每批開始先保存所需持股及 requestedAt。所有資產快照入口都要求這些持股已有該批或更晚的當日有效報價，不能混用當天早先的另一檔價格冒充完整更新。
- 同一批的 revision 允許分段補齊；晚回的失敗／較舊 tick 不能抹去已發布的有效價格。更舊批次不能蓋過新批次。
- 持股完成即可背景寫今日快照，不必等非持股；快照交易還會核對 refresh 身分、當日有效性及估值價格，避免檢查後又啟動新更新的競爭。既有歷史快照與帳務不重算。
- 保留盤中紀錄及原估值口徑，不把即時／參考價格改稱已確認收盤價。

## 歷史行情

- AssetTrend、Watchlist、SoldTracker 共用 history.ts。MA 與小線圖的重疊日期會重用資料，相同代號的工作序列化；全域最多三個歷史區間同時讀取，與現價排程分開。
- IndexedDB 僅保存公開、未還原日 OHLC／成交股數及查詢涵蓋區間，不保存使用者、持股、憑證或 token。不同裝置各自建立快取；資料庫不可用時退回記憶體。上限 200 組代號、約 32 MiB 的序列化估計容量。
- 快取仍有重新核對時間：涉及今日的區間五分鐘、近期區間一天、更早區間一週。來源修正會取代該查詢區間。失敗不能記成成功空資料。
- 超過一年自動切為每段最多 365 個日曆日（含首尾、日期差小於 365 天），按日期合併去重；涵蓋週末或合法空區間仍可快取。
- 富果歷史與現價的本機及後端滾動額度分開，各保留跨裝置 55 次／70 秒的保守限制。富邦歷史另設同樣的保守滾動限制；快照不會因歷史下載而共用這個池。
- 首次 100 檔仍需 100 個逐檔歷史查詢；每天要求全部最新仍可能跨分鐘。快取減少重複讀取，並不把 100 檔的新資料變成一次請求。

## 富邦歷史切換的限制

新增受 Firebase 身分驗證、白名單及配額保護的 fubon-history 函式，沿用既有伺服器 SDK／憑證，僅回傳有效日 OHLC／成交量，不回傳 SDK 原始錯誤或額外欄位。

`VITE_FUBON_HISTORY_ENABLED=true` 才允許前端使用富邦歷史；另外仍需啟用既有富邦快照設定。**預設停用**。使用者提供的 .env 沒有富邦登入／憑證設定，故本批不能宣稱已完成真實帳號歷史權限或資料一致性驗證。未驗證前仍使用富果歷史，已完成的快取、分段及排程改善照常生效。

後續在獲批准的驗證環境，以既有伺服器設定檢查上市、上櫃、IX0001 的權限、同期間 OHLC／股數單位與價格口徑；通過後才啟用富邦歷史作主源。失敗會有限度轉回富果。這不需要前端金鑰，不新增證交所行情替代流程或伺服器常駐排程。

- 瀏覽器檢查涵蓋逐檔先顯示、部分持股不寫快照、切換資產趨勢及知識庫、完整持股估值、富邦較舊價格不回退、僅一個背景市場請求、IndexedDB 重載重用及手機狀態列。

- 342 項相關回歸測試全數通過，涵蓋現價／歷史／資產快照、估值、報酬、手動 TWR 保存、相關資料安全、介面與同步。
- TypeScript／Vite build／lint 通過；build 前置 runtime 6/6 通過。沙箱的本機 JWKS 連線限制改由已批准的沙箱外建置驗證，並非停用測試。只剩既有大型 chunk 提示。
- 真實應用元件搭配隔離假資料的 Chromium 驗證通過：第一檔持股先顯示；切到 AssetTrend、再到 KMS 並等待頁面載入後，背景仍繼續；持股完整前沒有當日快照，完整後資產 103000＝市值 23000＋現金 80000；晚回富邦較低價格不覆蓋持股；背景市場請求一次。
- IndexedDB 真正寫入後重新整理，第二次歷史請求為 0。390／844／320 寬度的狀態列與更新中的估值提示通過；圖片僅存聊天私有 visualizations，未包進網站。
- 100 檔冷快取讀取 100 次，重複範圍不再查詢，新增 5 檔只多 5 次；20 檔同時回來合併一次部分資料交易，不排出 20 筆連續交易。
- 新增真實 runtime entry 測試、未驗證富邦不能成主源、跨年及閏年分段、失敗／空資料區分、帳號切換與快照交易競爭保護。

## 部署驗證補正

- 正式驗證確認富果現價／指數歷史、富邦快照、AI 狀態及 Google 每日報告皆回傳200，資產趨勢兩條曲線正常。25項既有持久設定部署前後指紋一致，20項Functions覆寫齊全，部署鎖恢復。
- 午夜後的有效前一交易日快照原會佔滿10個補查名額，讓少數快照未涵蓋代號未獲補查。現在先補查缺少／失敗／無有效價格的代號，再補查日期較舊但仍有價格的代號；持股優先請求、10檔上限及來源日期保護不變。新增回歸涵蓋15檔舊快照加2檔缺漏、有限名額與隔日快照防護，111項受影響檢查通過。
- 正式來源已回前一交易日行情時，不因此建立今日資產快照；首次資料及冷啟動仍需要等待，無法承諾固定秒數。
