# 年度資料最後成功時間

本機版本：`v26.9.30.8`。正式站仍為 `v26.9.30.7`；本批尚未部署，依 AGENTS.md 等待使用者另行批准。

行事曆設定頁底部增加一行 12px 淡色文字：年度資料最後成功更新時間，固定以台灣時間顯示。沒有新增卡片、按鈕或彈出通知；其他頁面沿用既有缺年提醒。

時間取自 `sharedData/annualCalendars` 中通過完整年度驗證的最新 `checkedAt`，API 先計算時間，再合併內建日程，避免將內建資料誤認為排程成功。這是最近有資料成功檢查並保存的時間；不代表尚未公布的下一年度已經齊全。失敗時保留既有時間，瀏覽器讀取與重新開啟不會改成現在。API 沿用既有五分鐘快取，最新執行結果可能延後五分鐘反映。

瀏覽器快取僅保存公開年度日程與時間，時間需對應已驗證資料列。舊版沒有時間欄位的快取仍可使用日程，待新版 API 回應後補上時間；沒有可驗證時間時顯示「尚無時間紀錄」。沿用原有資料讀取，不新增網路請求、資料庫文件、排程或服務成本。

驗證：

- 年度資料 28 項測試通過，涵蓋 API 的內建資料與雲端紀錄分別處理、部分成功、全部失敗、離線快取、損壞資料、不虛構時間、即時通知及台灣時間格式。
- Google 連結保護與缺年提醒相關 41 項測試通過；建置前的現代 Functions／Firebase runtime 6 項測試通過。
- `npm run lint`、TypeScript 與正式建置通過；建置保留既有 Fubon 啟用旗標。本批沒有部署或更動正式環境。
- 實際 CalendarSettings 元件搭配公開日程及記憶體 Firebase 測試資料：390×844 與 844×390 皆無水平溢出，時間文字高 18px，沒有新增按鈕。資料載入後原畫面立即更新，測試寫入為 0。
