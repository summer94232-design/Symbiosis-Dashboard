# A02 時間差與元大帳務規則核對（2026-10-01，Asia/Taipei）

本次後續修正版本為 `v26.10.1.2`，已併入正式版本 `v26.10.1.4`，見 [發布紀錄](RELEASE_2026-10-01.md)。這份說明補充 [A01～A09 修正說明](AUDIT_FIXES_2026-10-01.md)。核對範圍是系統的記帳、庫存、當沖、交割與費稅計算；「存檔成功」表示帳本寫入成功。

## A02：相隔 30 分鐘如何判斷

每次存檔重新讀取伺服器交易與股利，依成交日期／交易順序重算可售庫存。提交交易時核對帳本版本；其他裝置已改動帳本則重新讀取。沒有 30 分鐘的鎖定、有效期或時間去重條件。

假設同一股票原有可售現股 1,000 股，兩筆都是一般庫存賣出：

| 第一台已存入 | 第二台 30 分鐘後存入 | 結果 |
|---|---|---|
| 賣 600 股 | 再賣 600 股 | 第二筆缺少 200 股，拒絕寫入；第一筆保留。 |
| 賣 600 股 | 再賣 400 股 | 兩筆均成功，剩餘 0 股。 |
| 賣 600 股，之後補登較早成交但漏記的買入 300 股 | 再賣 600 股 | 兩筆均成功，剩餘 100 股。 |

有效的庫存增加也會納入重新計算，但今日零股買入不能補足今日賣出。歷史交易仍依實際成交日期登錄，不能為通過檢查而移動日期。

A02 是帳本併發與超賣保護。兩台各自新增不同文件 ID 的紀錄，沒有僅因時間、金額相同就合併的規則。只有原表單沿用相同文件 ID 重試時，已成功的相同資料會略過。因此同一筆券商成交不應在兩台各另建一筆；若庫存足夠，超賣檢查本身無法辨認這種人工重複。

## 本次另修正的規則邊界

1. **現股與融資分開檢查。** 可售股數現在依剩餘買入批次的交易類別計算，避免現股賣出誤用融資股數、融資賣出誤用現股。合法現股賣出不會扣掉融資本金。
2. **零股當天買入不當作當沖可用股數。** 今日零股買入，包含湊成整張的情境，不能補足今日賣出；次一交易日可使用。合法普通整張當沖及明確標記的先賣後買待回補仍保留。[元大當沖交易說明](https://www.yuanta.com.tw/eYuanta/%3B/Node/Index?C1=2021102007380647&C2=2021102005758265&ID=2021102005758265&Level=2&MainId=00415)
3. **原持股賣光仍收到已取得的配股。** 除權後賣出不會喪失先前取得的股利權利。具實際配發日的已收錄股票股利，配發時會重新建立持股；公告尚未確認的資料不入帳，配發前也不作可售庫存。原買入成本已隨原股票全數實現，重新收到股份不憑空增加購買支出。[證交所除權息問答，第 6 題](https://investoredu.twse.com.tw/pages/TWSE_InvestmentQA.aspx?ID=1)
4. **帳面現金與交割銀行餘額說清楚。** 首頁「可用現金」改為「帳面現金」，說明按成交日計入且包含未交割款。負值提示改為核對交割款，避免以成交日資金缺口直接斷言違約。元大月結單 CMA 核對仍按實際交割日期調整月底未交割款；真正入金仍保留實際轉帳日期與收盤後假設。一般台股是 T+2 營業日交割。[元大交割與當沖說明](https://www.yuanta.com.tw/eYuanta/%3B/Node/Index?C1=2021102007380647&C2=2021102005758265&ID=2021102005758265&Level=2&MainId=00415)

## 已核對並保留的計算與實際資料優先順序

- 買入收付含實際手續費；融資買入另扣借款。融資賣出收付扣費稅與償還總額，損益只扣利息，不把償還本金再當成損失。
- 融資估算以尚未償還的批次計本金，交割日用已載入的年度結算日曆推算 T+2，利息按批次年利率及兩次交割日之間的日曆天數／365 計算。元大實際本金、利息與償還總額可覆寫估算；個人優惠利率及逐筆尾差不宣稱已與私人帳戶核實。[元大融資庫存說明](https://www.yuanta.com.tw/eYuanta/securities/aporder/Instructions/836878aa-5e5f-4dc8-9d18-984e9bf5c1cd?TargetId=36ffcbec-d512-4fa8-9124-a9eac7e66f5e&TargetMode=2)
- CSV 的實際手續費、交易稅及明確 0 優先保留。A05 的債券 ETF 稅率規則依商品和日期套用，未擅自延長尚未確認生效的免稅期間。持倉預估變現費稅仍為試算值。
- 指定庫存沖抵與 FIFO 保留，依元大對帳結果調整指定批次。若已成交賣出被擋，應先核對交易類別、漏登買入或配股，補齊帳本，而非改動實際成交股數。

**當沖自動配對有明確限制：** 相同日期買賣不保證元大認列當沖。資格、已簽契約、標的當日可沖狀態及停止先賣後買仍須以元大為準；系統未連線查詢個人資格或逐日停沖名單。既有「排除當沖」及手動配對可保存實際認列結果，費稅也不因自動配對重寫。先賣後買尚未回補只保留待回補紀錄，不憑空產生已實現收益。融券、借券強制買回與資券互抵沒有完整模型，本次沒有增加這些產品範圍。[元大當沖限制與情境說明](https://www.yuanta.com.tw/eYuanta/%3B/Node/Index?C1=2021102007380647&C2=2021102005758265&ID=2021102005758265&Level=2&MainId=00415)
