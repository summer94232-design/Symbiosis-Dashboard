# 畫面錯誤復原與年度資料提示（2026-09-30）

顯示版本：`v26.9.30.3`。沒有新增付費服務、沒有部署，也沒有變更正式資料。

## 變更

- 入口加入全域 React 錯誤邊界；路由頁面另有獨立邊界，頁面 render／lifecycle／lazy import 失敗時顯示復原操作並保留側欄。切換路由會重新建立頁面邊界。
- 復原畫面提供重新載入、返回儀表板，以及未儲存輸入的提醒；不把錯誤內容或 stack 顯示給使用者。按鈕高度至少 44px。
- 用明確的已維護年份判斷年度資料覆蓋：FOMC 為 2025／2026 年；證交所交割休假為 2026 年。新增完整年度資料時須同步更新覆蓋年份。
- 月曆依查看年份與 FOMC 篩選顯示提示；每日簡報涵蓋未來 14 天跨年範圍；Google 設定與同步結果涵蓋未來六個月範圍，只有同步包含 FOMC 時才提醒。
- 融資賣出表單依歷史買入至賣出日期範圍顯示交割休假缺漏提示，包含年底 T+2 交割落到下一年。原有交割日、費稅、融資利息數值計算保持不變。
- 已有年度資料的空月份保持安靜，不把「該月沒有會議」誤報為資料缺漏。

## 驗證

- `npm test`：527／527 通過，含 11 項本批新測試；另 6 項函式執行環境測試通過。
- `npm run lint`：零錯誤／警告。
- TypeScript 與 Vite production build 通過；大型套件的既有建置提示仍存在。
- 隔離瀏覽器驗收：實際 React 頁面錯誤、lazy 載入失敗、全域錯誤、側欄切換與重新載入恢復；實際月曆切到 2027 年顯示提示，停用 FOMC 篩選後提示消失。
- 手機直向 390×844 與橫向 844×390 驗收復原畫面，暫時 viewport 已還原。
