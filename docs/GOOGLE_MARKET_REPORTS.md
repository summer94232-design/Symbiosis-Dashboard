# 台股每日投資報告

儀表板的報告卡片沿用行事曆設定中的共用 Google 連線。只讀取指定帳號擁有、名稱完全相符且未刪除的「台股每日投資報告資料庫」，不固定使用初始試算表 ID。

## 資料來源

後端以 Drive `files.list`、`createdTime desc`、`pageSize=1` 搜尋最新檔案，再以 Sheets API 讀取第一分頁 `A1:F`。第一列依序為「日期、時段、報告標題、摘要、全文、更新時間」，第二列起為報告。

日期及更新時間依規格以文字保存；日期需為有效 `YYYY-MM-DD`，時段僅允許盤前／盤後，更新時間使用台灣時間 `YYYY-MM-DD HH:mm:ss`。按日期、時段及更新時間排序，同日同時段取最新修訂；不以試算表最後一列決定最新報告。

最新檔案若空白、格式不符或已消失，最多再查兩份先前檔案，取得可閱讀內容並標示退回來源。缺漏資料與未來報告不當作已發布報告。API 或連線失敗維持錯誤狀態，不偽裝為未發布。

## 閱讀與更新

- 摘要卡片顯示最新報告、實際日期／時段及更新時間。
- 「閱讀全文」開啟閱讀視窗，可選歷史報告，支援 Markdown 標題、條列、表格與來源連結。原始 HTML 與不安全連結不執行。
- 進入儀表板即讀取，頁面在前景時每五分鐘檢查，重新聚焦亦檢查；「重新讀取」立即搜尋新表。
- 盤前約 08:55～09:00、盤後約 18:00～18:05，期間提示產生中；超過預計完成時間而缺少該時段報告則標示尚未發布。
- 週末不期待新報告；休市提示只使用已驗證的官方年度休市資料，缺少資料時不自行認定休市。
- 讀取失敗保留同一帳號上次內容並標示更新狀態未確認；切換帳號會清除畫面資料，過期請求不能回寫新帳號畫面。

## 權限與部署

後端驗證 Firebase UID、共用 Google 連線、Google userinfo 與報告讀取權限。Google token 不送到第三方網址或報告回應。Private cache 按 UID 與 Google grant 隔離，手動更新會取代舊快取。

正式使用仍須部署同意、在同一 Cloud 專案啟用 Google Drive／Sheets API，以及由使用者在行事曆設定完成補充授權。本機模擬通過不等於真正雲端連線已完成。
