# F05、F07、F19 修正紀錄（2026-09-08）

## F05：試算可執行股數與現金

賣出建議限制在目前持股可組成的交易單位內。100 股在整張模式下可賣 0 股；1,500 股可賣 1,000 股，剩餘 500 股保留。畫面提示改用整股模式處理零股。

零股數不收最低手續費；缺價格的交易保留待補價提示，但不計入買賣現金、費稅或假設已達到目標部位。hold 即使價格為 null／undefined，也不產生 NaN 市值。

## F07：自動快照隔離

防重入及 60 秒覆寫節流改按 invest UID 與日期分開。防重入鎖在第一次非同步讀取前取得，失敗也會釋放。移除記憶體中的「今日已存在」捷徑，每次補寫確認資料庫，讓已刪除的今日快照可以重新建立；跨帳號工作仍受原 session 檢查保護。

此為單一分頁內的防重入，不宣稱提供跨裝置交易鎖。

## F19：試算方案隔離

新版 localStorage key 包含 invest UID，讀寫綁定頁面啟動時的 session。主程式在 UID 改變時重新掛載 App；舊頁面保存時若帳號已變更，操作中止。儲存失敗會顯示錯誤，不先顯示保存成功的狀態。

舊版共用 key 沒有可驗證的帳號歸屬，因此保留原資料，不自動載入或歸戶。畫面提示在目前帳號重新建立方案。方案僅保留在此裝置的此登入帳號下，不在系統 JSON 備份內。UID 分 key 是應用程式的帳號隔離，不是瀏覽器資料加密。
