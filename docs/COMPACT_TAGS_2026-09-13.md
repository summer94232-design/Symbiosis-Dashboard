# 標籤管理緊湊版 — v26.9.13.4

依使用者回饋縮小手機標籤列：名稱、筆記數、上下移與編輯同列排列，編輯改用鉛筆圖示並保留可辨識名稱。一般列高由約 120px 降至 53px，44×44 的操作範圍維持不變；編輯時使用滿寬輸入列。縮小容器與頁首留白，桌面仍保留原有欄位及文字按鈕。

以隔離資料測試 320、375、390、430px 直向與 844px 橫向：列高皆為 53px，沒有整頁橫向溢出；子標籤展開、重新命名及排序通過。390×844 約可看到 11 個完整的一般標籤列，長名稱及展開子分類時依內容調整。1280px 桌面欄位及文字按鈕正常。

建置與異動 TypeScript 檔案的 ESLint 通過，仍有既有大型 chunk 警告。未部署，未操作正式資料；未經實體 iPhone Safari 驗收。
