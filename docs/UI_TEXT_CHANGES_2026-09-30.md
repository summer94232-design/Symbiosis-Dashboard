## B1–B7 的意思與目前決定

這些原本就只在特定操作、例外狀況或長內容出現，不是必須修復的問題。本次全部維持原樣，建議先觀察 A 類的效果。

| 項目 | 原本建議的意思 | 現在建議 |
|---|---|---|
| B1 未連結 Google 的說明 | 連結按鈕上方的長句縮成「連結後，可手動同步未來半年的行程」。 | 保留即可，只有尚未連結時看到。 |
| B2 當沖待核對／明細 | 縮短通則教學，保留有問題的交易及具體處理提醒。 | 保留即可，不能隱藏未回補或報表不完整的風險。 |
| B3 年度缺漏 | 警告改用較短句子，仍保留缺漏年份與估算風險。 | 保留即可，年度資料完整時本來就不顯示。 |
| B4 舊筆記最佳化 | 提示只寫有幾則可最佳化，技術原理點開查看。 | 保留即可，只有舊資料存在才出現。 |
| B5 Excel 匯入教學 | 必要欄位與合併方式留在畫面，日期格式範例點開。 | 保留即可，只有開啟匯入視窗才出現。 |
| B6 新增快照教學 | 移除 Firebase 等實作名詞，直接說會帶入已扣融資的淨資產。 | 保留即可，只有新增快照時出現。 |
| B7 每日重點的長行程備註 | 顯示 1–2 行預覽，點開完整備註，不刪除內容。 | 日後真的遇到備註太長再改；沒有讀取使用者的實際行程。 |
