16 項 AI 設定使用 Netlify 官方 CLI 的 `--env`／`--secret-env` 部署覆寫，解析結果逐項確認 `scopes: ['functions']`。Gemini 金鑰與知識庫服務帳號為 secret。這些設定只供該部署的 Functions 使用，保留原有站台登入與行情憑證；舊 `VITE_GEMINI_API_KEY` 已從站台變數移除。沒有升級方案或擴大機密的可用範圍。

原因：新增 Functions 指定範圍的專案變數被 Netlify 以 HTTP 403 拒絕，要求升級方案。改成全範圍的操作遭自動核准審查拒絕，理由為擴大機密存取範圍；該操作未執行。最後採用較窄的 Functions 專用部署覆寫完成發布。

**未來發布必須重新帶入同一組 16 項部署覆寫，不能直接省略。** 它們不是持久的站台環境變數。設定包位於被 Git 忽略的 `local-secrets/ai-netlify-functions.env`；不要將內容輸出、提交至 Git 或放入前端。只有新的更新批次取得明確批准後，才可再次部署。
